# Интерфейс новостей sport_pari

Реализован фронтенд News Service на существующем FastAPI с Jinja2, CSS и небольшим JavaScript для состояний форм и локального времени. Сборщик JavaScript и дополнительная UI-библиотека не требуются.

## Общий слой

- `app/ui/static/tokens.css` содержит единственный набор семантических цветов, радиусов, отступов и подключение локального Inter с кириллицей. Лицензия шрифта сохранена рядом с файлом.
- `app/ui/static/app.css` задаёт оболочку, навигацию, карточки, формы и адаптивные состояния.
- `app/ui/templates/base.html` содержит AppShell, верхнюю панель, меню пользователя и область сообщений.
- `app/ui/templates/components.html` содержит общие иконки, навигацию, карточку новости, объяснение рекомендации, сообщения, пустое состояние и пагинацию.
- `/preview/components` показывает компоненты, ошибки, пустую выдачу и образец skeleton с явной подписью демонстрации.

Основные цвета соответствуют предоставленной дизайн-системе. Для границ интерактивных полей и вторичных кнопок введён дополнительный семантический токен `control-border = #6A8296`. Исходный `border = #294052` используется для разделителей. Контраст границы управления превышает 3:1 на всех трёх поверхностях. Контраст текстовых токенов на основных поверхностях превышает 4.5:1.

Кнопки и поля имеют высоту от 44 px, карточки — радиус 12 px. На широком экране боковая навигация занимает 240 px. Ниже 1280 px она доступна по кнопке, ниже 768 px контент и карточки располагаются в одну колонку. В фильтрах используется собственная горизонтальная прокрутка списка видов спорта. Страница сохраняет ширину экрана. Есть видимый клавиатурный фокус, ссылка перехода к содержимому и `prefers-reduced-motion`.

## Экраны

- `/preview` — общая лента с поиском, видами спорта, датами, источниками, доступными изображениями и пагинацией по 12 материалов.
- `/preview?view=for-you` — персональные рекомендации с объяснением. Учитываются реальные интересы и история владельца сессии.
- `/preview/news/{id}` — статья, дата, источник, RSS/API-анонс, оригинал публикации и комментарии.
- `/preview/profile` — вход и настройки интересов именно новостной ленты. Полный кабинет User Service в эту задачу не входит.

Параметры поиска, выбранный вид спорта, вид ленты и страница сохраняются в ссылке возврата из статьи. Внешние адреса для возврата отклоняются. Гостевой переход из персональной выдачи ведёт на вход с сохранённой целью. Продолжение без входа открывает общую ленту с прежними фильтрами.

## Интеграции и состояния

Рендеринг использует существующие репозитории новостей и комментариев и тот же `RecommendationService`, что API. Авторизацию и запись интересов выполняет клиент существующего `user_svc`. Сохраняется текущая схема Bearer и HttpOnly cookie. Пароли не сохраняются. Собственные регистрация, роли и пользовательское хранилище не добавлялись.

Формы блокируют повторную отправку и показывают состояние выполнения. Успех появляется после ответа сервера. Ошибка входа возвращает страницу с сохранённым именем пользователя. Ошибка сохранения интересов сохраняет выбранные значения, пока сессия доступна. Черновик комментария остаётся при валидации и дополнительно сохраняется в sessionStorage до успешной отправки. В браузерном хранилище находятся только тексты черновиков.

Для гостя поле комментария заменено предложением войти. Истёкшая сессия обрабатывается отдельно. Недоступные статья и хранилище получают страницы ошибок с последующим действием. Пустой результат поиска предлагает сброс фильтров. Текст статей и комментариев экранируется Jinja2. Ошибка загрузки изображения скрывает изображение, сохраняя карточку.

## Данные

Настройки импорта включают 12 видов спорта. Для баскетбола и хоккея используются несколько источников — BBC Sport, CBS Sports и публичный JSON ESPN. Остальные разделы включают футбол, теннис, Формулу-1, регби, крикет, лёгкую атлетику, гольф, велоспорт, бокс и бейсбол. Повторный импорт обновляет отсутствующие изображения и сохраняет ID, редакторские тексты и историю.

Фильтр заголовков исключает рекламные материалы о ставках, промокодах и fantasy-играх. Данные источников публикуются на исходном языке. Полный текст читается по ссылке на оригинал. Искусственное демо отдельно помечено на странице и карточках.

Чтобы один раздел не вытеснял другие при большом импорте, в корпус ранжирования попадает до 75 последних статей каждого вида спорта, всего до 1000. Свежесть и правила ранкера затем применяются к этому корпусу.

## Границы интеграции

Навигация других сервисов помечена как неподключённая. Связанные матчи и вопросы отсутствуют в контракте статьи. Их ID не выводятся из слов заголовка. Каталог команд не предоставлен, поэтому интерфейс сохраняет существующие ID команд при изменении спортивных интересов и показывает состояние недоступного каталога. Модераторский интерфейс и CMS не добавлены. Редакторский API остаётся защищён серверным ключом.

## Запуск и проверка

```bash
uv sync
uv run python -m app.demo --real --port 8003 --user-service-url http://127.0.0.1:8002
```

Для PostgreSQL примените `uv run alembic upgrade head`, загрузите данные через `uv run python -m app.ingest` и запустите API с `PREVIEW_ENABLED=true`. В существующем compose профиль `ingest` обновляет все настроенные источники каждые 15 минут.

Проверьте общую и персональную ленты, переключение хоккея и баскетбола, поиск без результатов, следующую страницу, возврат из статьи, отправку комментария, ошибку входа и мобильное меню. Автоматические проверки запускаются командой `uv run pytest -q`.
