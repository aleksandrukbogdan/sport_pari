# news_svc

Микросервис платформы sport_pari: лента материалов, карточка новостей, комментарии и поиск по ним + возможно рекомендательная система в зависимости от интересов пользователя(к следуюшему спринту нарежем задачи в беклог).

Сейчас в `app/` только заглушка: создаётся приложение FastAPI и отвечает `GET /health`.

Postgres в compose поднят заранее, чтобы к нему подключить хранилище, когда появится схема(мб лучше документоориентированная бд)

## Запуск

Из каталога `news_svc`:

```bash
docker compose -f deploy/docker-compose.yml up --build
```

- API: http://localhost:8000
- OpenAPI: http://localhost:8000/docs

Проверка:

```bash
curl -s http://localhost:8000/health
```

Локально без контейнера API:

```bash
uv sync
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Образ API собирается тем же `uv`: зависимости ставятся из `uv.lock`, каталог `app` импортируется из рабочей директории.
