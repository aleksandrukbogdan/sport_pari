## Детерминированная проверка HTTP-клиента

С фиксированным временем `2026-11-08T12:00:00Z` и HTTP MockTransport:

- 215 пользователей прочитаны страницами с first=0, 100, 200 и max=100;
- просроченные даты с положительным и отрицательным UTC-смещением выбраны;
- будущие даты с обоими типами смещения сохранены;
- проверены суффикс Z и срок, точно равный времени начала выборки;
- повреждённые даты, даты без часового пояса, null вместо даты, скаляр
  вместо списка и несколько дат пропускаются; предупреждения содержат ID;
- отсутствие даты или атрибутов не прерывает обработку;
- пустой realm и ровно 200 пользователей корректно завершают обход;
- при 503 на второй странице ни один DELETE не выполняется, клиент закрыт,
  ошибка записана в лог.

Проверка пройдена. Существующий тест частичного сбоя удаления — 2 passed.

## Проверка настоящего Keycloak

Использованы PostgreSQL и Keycloak 26.0 из текущего Compose, временный
realm и собранный образ API:
`sha256:6ded746edfa7d6e35eb566865cb53463311d40add9c5802eefcd9b961db62002`.

В realm созданы 105 пользователей с атрибутом срока удаления. У двух срок
прошёл; один из них заведомо не входил в первую сотню. Остальные записи
имели будущую дату, повреждённую дату, дату без часового пояса либо
несколько значений.

Проверены:

- выборка ровно двух просроченных пользователей, включая запись за первой
  страницей;
- запуск `cleanup_deleted_users` внутри собранного контейнера API;
- 404 для обоих удалённых пользователей;
- сохранение будущих и повреждённых записей;
- уменьшение общего количества пользователей ровно на два;
- повторный запуск не меняет число оставшихся пользователей.

Существующий набор на этом же окружении:
`python -m pytest tests -q` — **3 passed за 5.20 с**.
Сборка Docker-образа и `git diff --check` завершились с кодом 0.

Временные контейнер API и realm удалены после проверки.
